# 출장 및 유류비 정산 관리 시스템 (Business Trip & Fuel Expense Portal)

반응형 웹 기반으로 출장 내역 관리, 유류비/식대/통행료 자동 정산, 네이버 지도 연동 경로 증빙, 그리고 사내 공식 양식(Excel/PDF/ZIP) 일괄 출력을 지원하는 서버리스(Frontend-Only) 웹 애플리케이션입니다.

## 1. 프로젝트 개요
- **목적**: 영업 및 현장 출장자의 출장 내역 기록, 규정 기반 실비/유류대 산출, 증빙 자료(영수증, 지도 캡처) 취합, 사내 보고용 공식 문서(Excel/PDF/ZIP) 원클릭 생성 지원.
- **특징**:
  - 별도의 백엔드 데이터베이스 서버 없이 브라우저 로컬 저장소(`localStorage`, `IndexedDB`)와 세션(`sessionStorage`)을 활용한 완전한 프론트엔드 환경.
  - 내장된 압축/문서 생성 엔진(`JSZip`, `pdf-lib`)을 통해 브라우저 단에서 엑셀 및 PDF 문서를 직접 생성 및 번들링.

## 3. 핵심 파일별 상세 기능

### 3.1. `index.html` (로그인 포털)
> 파일 링크: [index.html](file:///C:/Users/Jackson/Documents/code/김진영/index.html)

출장 정산 시스템으로 진입하기 위한 인증 게이트웨이 페이지입니다.

- **인증 메커니즘 (`window.fetchLocalConfig`)**:
  - 로컬 `config.json`을 비동기 조회하여 설정된 `secret_key`와 사용자가 입력한 비밀번호를 대조 검증.
  - 인증 성공 시 이동할 `target_page` 경로(`summary.html`)를 취득하고 `sessionStorage`에 인증 토큰(`secret_code`)과 세션 사용자 정보(`current_user`)를 저장 후 자동 리디렉션.
  - 로컬 설정 파일 부재 시 서버 API(`/login`, `/config`)로 자동 폴백.
- **UI 및 편의 기능**:
  - **아이디 저장**: `localStorage`에 아이디를 저장하여 재방문 시 자동 입력 및 포커스 제어.
  - **비밀번호 보기/숨기기**: 눈 모양 아이콘을 통해 비밀번호 텍스트 가시성 토글 (`window.togglePasswordVisibility`).
  - **빠른 체험 계정 채우기**: `window.fillDemoAccount('김진영')` 버튼으로 간편 입력 지원.
  - **상태 피드백**: 로딩 스피너 및 에러 메시지 배너 동적 제어 (`window.showError`, `window.hideError`).

### 3.2. `summary.html` (정산 관리 대시보드)
> 파일 링크: [summary.html](file:///C:/Users/Jackson/Documents/code/김진영/summary.html)

출장 등록, 계산, 증빙 관리, 검색, 통계 및 보고서 파일 생성을 담당하는 메인 애플리케이션 화면입니다.

- **보안 가드**:
  - 페이지 로드 전 및 스크립트 실행 초기에 `sessionStorage.getItem('secret_code')` 검증. 미인증 사용자의 URL 직접 접근 시 경고 후 [index.html](file:///C:/Users/Jackson/Documents/code/김진영/index.html)로 강제 리디렉션.
- **대시보드 KPI 카드 (5개 핵심 지표)**:
  - 총 출장 건수, 총 이동거리(km), 유류대/대중교통비 실비 합계, 식대 청구 합계, 총 청구 합계액을 실시간 집계 표시.
- **조회 및 필터 컨트롤러**:
  - 조회 시작일/종료일 선택, 이동수단 구분(전체, 자가차량, 대중교통), 키워드 검색(방문지/출장자/목적).
  - 빠른 기간 프리셋: 전체, 이번 달, 정산주기(전월 26일~당월 25일), 전월, 필터 초기화.
- **출장 내역 테이블 및 관리**:
  - 컬럼별 정렬(출장일, 주행거리, 총 청구액 ↕ 토글).
  - 데이터 행 클릭 시 출장 상세 정보 모달(`dialog id="detailModal"`) 팝업.
  - 개별 출장 수정 및 삭제 기능.
- **출장 입력 / 수정 다이얼로그 (`dialog id="tripInputDialog"`)**:
  - **01. 출장 정보**: 출장일, 이름, 부서, 출발지, 방문지·경유지, 출장 목적, 출퇴근 형태(일반 복귀, 직출, 직퇴, 직출·직퇴), 동행인 입력.
  - **02. 이동거리 및 기준**: 이동수단(자가차량 / 대중교통), 유종(휘발유, 경유, LPG, 전기차), 주행거리(km), 연비/전비, 유가/단가 입력에 따른 유류비 실시간 자동 산출.
  - **03. 지출 금액**: 식사 인원, 중식 결제액, 석식 추가 옵션 및 결제액, 통행료, 주차비, 대중교통비, 비고 메모 입력 및 총합 계산.
  - **04. 증빙 첨부**: 영수증 파일(이미지/PDF) 및 네이버 지도 연동 증빙 첨부.
- **네이버 지도 연동 및 경로 캡처 다이얼로그 (`dialog id="naverMapDialog"`)**:
  - 출발지/도착지 기준 네이버 지도 길찾기 웹 바로가기 연동.
  - 네이버 지도 길찾기 결과 URL 또는 텍스트 복사-붙여넣기 시 거리(km)와 통행료(원) 자동 파싱 및 적용.
  - 화면 캡처 클립보드 붙여넣기 지원: 캡처 도구(`Win+Shift+S`) 후 모달 내에서 `Ctrl+V`로 즉시 이미지 첨부.
- **문서 및 보고서 출력 엔진**:
  - **회사 정산양식 파일(ZIP) 생성**: 사내 공식 엑셀 템플릿(Base64 OpenXML) 파싱 및 데이터 치환, Canvas 및 `pdf-lib` 기반 영수증/지도 증빙 PDF 조판 후 하나의 ZIP 파일로 번들 다운로드.
  - **CSV 내보내기**: 스프레드시트 호환용 CSV 파일 다운로드.
  - **인쇄(Print)**: 인쇄 전용 CSS 미디어 쿼리를 통한 깔끔한 A4 규격 출력 지원.
  - **로그아웃**: `sessionStorage` 클리어 후 로그인 화면 복귀 (`window.handleLogout`).

## 4. 정산 비즈니스 규칙
1. **식대 청구 한도 규정**:
   - 1인 1식당 최대 인정 한도는 **10,000원**입니다.
   - 인정 금액 산식: `Math.min(결제금액, 인원수 * 10,000원)`
   - 동행인이 있는 경우(2인 이상) 동행인 이름 및 부서명 입력 필수.
2. **유류비 계산식**:
   - 자가차량 유류비 = `(총 이동거리 ÷ 차량 연비) × 적용 유가` (원 단위 반올림)
3. **정산 주기**:
   - 매월 **전월 26일 ~ 당월 25일**을 기본 정산 사이클로 지원.
